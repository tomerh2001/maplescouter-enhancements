# GMS feature audit, October 14, 2026

Scope: requested GMS Link Skill suggestions and related GMS omissions. This was a targeted feature audit, not a replacement for the weekly full-site translation audit.

## Findings and release

Prepared version **1.7.7**. The current bossing optimizer already has Hayato, Kanna, Lynn and Mo Xuan. The separate Result Link Skill efficiency table does not. Added their current Lv. 2 effects and Lv. 2 to 3 increments to that table, with an active-effect control, threshold checks, conditions, and one sorted list. Removed Lethe's Covenant from GMS suggestions, following the optimizer's own region filter.

Corrected the old Grounded Body translation to Qi Cultivation, added Elementalism to the locale patch, and translated Erel Light. Added a separate Guiding Stars consideration with the individual Lv. 3 effect confirmed by Nexon. Its buff-duration benefit is not assigned a fabricated damage score. See [sources and limits](../GMS-LINK-SKILLS.md).

Fresh route crawl: 68 successful pages, 190 active chunks, 19 new downloads, no crawl failures. Static checks found current GMS class entries including Sia/Erel, their HEXA assets, and familiar passive-skill support already present in the input/result paths. No unrelated calculation models were added or changed.

## Validation

- 124 Node regression tests pass, including 13 new Link Skill tests: region gates, critical thresholds, active effects, upgrade increments, own-class exclusion, equipped aliases, Vicious Shot, Demon Avenger, malformed coefficients, source selection, native ties, and fail-safe parsing.
- Userscript syntax and `git diff --check` pass.
- Chrome and Firefox packages build at 1.7.7.
- Firefox lint: 0 errors, 0 notices, 11 existing warnings (Android consent minimum version plus pre-existing dynamic HTML warnings). No new dynamic HTML assignments were added.
- Real internal-browser checks on an isolated localhost proxy of the current site, using its live calculation API and built script at document start. The site's sample Lv286 Mercedes returned nonzero Normal/HEXA and Boss 300/380 results.
- GMS normal and Lv. 2 to 3 mode, active effects on/off, 300/380 toggle, tab unmount/remount, and sorting all checked. The native KMS list reappears when the result region becomes KMS. The temporary result change was restored.
- Desktop 1440x1000 and phone 390x844 checked. Phone table width 326px, no horizontal overflow, all 18 row icons loaded. No duplicate GMS list after returning from WSE Potential.
- Screenshot: [GMS table](2026-10-14/gms-links.png).
- Runtime log showed the known initial React hydration warning (#418), no new feature exception.

## Limits

The browser check used a manual result; API source selection and equipped-link cases were covered in regression tests rather than a signed-in character session. Firefox package lint passed; Gecko runtime was not exercised in this session. No real character/cloud saves were modified. The original site still owns the full damage model and optimizer. This is an efficiency estimate, not a twelve-slot loadout solver, and the conditional cases and unsupported effects are documented.
