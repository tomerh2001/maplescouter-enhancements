# MapleScouter audit, 8 October 2026

Release: **1.7.6**. This completes the interrupted October 1 work on top of the separate 1.7.5 repository rename release. The Mac checkout keeps its existing directory; its origin now uses `tomerh2001/maplescouter-enhancements`. Unrelated untracked research files and real character saves were preserved.

## Findings and changes

- Crawled 68 public routes and 189 active JavaScript files. Compared with the last completed live audit on September 24, 50 files changed and `/simulator/soul` was added. Extracted 7,274 Korean literals with no crawl or parser failures. The final scan has zero unresolved literals and 22 explained exceptions. This measures the scanned code, not every possible API response or logged-in screen.
- Added 65 reviewed translation entries across the October 1 and October 8 overrides. They cover Soul Amplification, Soul Potential rerolls, guarantee progress, equipment messages, Inner Ability constraints, Level 3 Link Skills, and the ranking filter for CDR of 7 seconds or more. Generated messages preserve equipment names, probabilities, counts and costs.
- Fixed a React crash when Soul amplification succeeds and replaces the unamplified card with a Potential card. The translation layer now keeps the simulator's text nodes intact instead of replacing their parent contents. Stage labels and reroll counts still update when React changes only the numeric node.
- Made Soul simulator tables and cost buttons wrap at phone width, keeping labels and numbers readable.
- Browser checks found two ranking errors absent from the static missing-string report: split `5기` tab labels and a description stuck at `Season N`. Tabs now say `Season 5`, etc. The i18next entry intentionally retains `N기` until the site's own `.replace()` fills it; the DOM layer then translates the completed sentence. Changing season updates both the selection and description. The tab rule is scoped to Training Grounds so it cannot change outfit series names.
- No game calculations, store identities, permissions or build dependencies changed. The 1.7.5 repository links and installed userscript namespace are retained.

## Validation

- 111 Node regression tests passed, including Soul success/update node preservation, dynamic messages, ranking interpolation, numeric values, cloud conflicts and failures, stale sync checks, request limits, relative dates, region loading, locale persistence, and store publishing safeguards.
- Built both packages as 1.7.6. JavaScript syntax, ZIP integrity, manifest versions and whitespace checks passed. Firefox lint: 0 errors, 0 notices, 11 existing warnings (Android minimum-version declaration and dynamic HTML assignments).
- Used the supported internal Chromium browser against the native live Soul page and the current site through an isolated proxy at `localhost:8796`. The proxy injected the built release at document start and served the audit's current immutable chunks; calculator requests reached the live API.
- Soul: automatic amplification to Stage 4 completed without a React removal error. Switched to Soul Potential, rerolled for 20,000,000 mesos, selected the new result, and switched back. Desktop and 390px phone layouts were inspected. The phone document width was 390px, with no horizontal overflow; table headings, guarantee counts and costs stayed readable. The known initial React hydration warning remains; no amplification crash appeared.
- Floating-layer fixture: choosing a menu item left no stale clone. A tooltip stayed readable after its native layer was removed while hovered. Pointer leave and Escape dismissed it.
- Created only the local test character `Audit1008` from the site's sample Mercedes. Changed level 286 to 287, reloaded, and confirmed both selection and level persisted. The picker showed a local-only character and consistent relative dates. No automatic upload occurred.
- Downloaded the test character JSON and verified the native type, version, IGN, label and level. Imported it and replaced that same local character successfully. The browser download event timed out, but the saved file and completed re-import verified the operation.
- GMS selection survived reload. English to Korean and back worked. Result and Detailed Information stayed in English. The live sample returned Normal 727,549,621, HEXA 295,492,758, Boss 380 Normal 104,774 and Boss 380 HEXA 73,784. These are observed outputs, not an independent validation of the server's damage formulas. The manual HEXA recommendation page loaded and switched to After Reset.
- Training Grounds: Season 5 and Season 4 showed matching descriptions; the translated 7-second CDR filter could be checked.
- A read-only production cloud HEAD request returned HTTP 200, an ETag and `Access-Control-Allow-Origin: *`. No production character was uploaded, overwritten or deleted. Cloud failure/conflict/freshness behavior was covered by regression tests, not production writes or a second physical PC.
