# UI compatibility and maintenance — 2026-10-26

Version: **1.7.15**. Continues the interrupted October 22 audit against the site's newer October 26 build.

## Changes

- Support the new `/en/manual/input`, `/en/manual/result`, `/en/manual/hexa` and `/en/manual/optimizer` workspace, retaining support for the original URLs. The input route now mounts the character picker, hides the native preset row, and applies the existing contextual help and Destiny 2 labels.
- The new Result URL no longer supplies `?manual=true`. Read its manual calculation store so GMS Link Skill suggestions and **Max level** use the correct character. The original API-character Result route still reads its separate store.
- Keep the active manual navigation item visible on narrow screens. Reposition only when the selected page or layout changes; ordinary horizontal scrolling remains available.
- Restore the layout scope immediately after React hydration removes it. Previously, ranking filters and the Treasure Hunter layout could overflow until the two-second housekeeping pass. Both fit at 1280px immediately after the fix; wide data tables retain their local scroll areas.
- Review 348 override entries across the October 22 and October 26 files: manual navigation and guidance, account linking, profile borders, donation information, current KMS-only labels and potential effects. Individual potential lines reuse translations already reviewed in the probability tables. Fix comma-separated hour counts, split farming-minute labels, ranking dates and dynamic border allowances without changing their numbers.
- Preserve the literal Korean account-deletion confirmation word inside its English instruction. The server requires that exact token; translating it on a second observer pass would break the form. No account action was performed.

No game formulas or extension permissions changed. Character options and result summaries retain their existing layouts.
