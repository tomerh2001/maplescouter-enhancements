# Boss phase popup translations — 2026-10-28

Version: **1.7.16**.

## Changes

- Translate the phase rows produced after the site splits each boss plan on `/`. Previously, whole-plan dictionary entries were unreachable in this popup, and the numeric rule only understood basic full/semi-burst counts.
- Cover entry bursts, mini-burst openings, Origin timing, remaining mini-bursts, Ascent casts, special-pattern exclusions and Kalos subphases. Use full bursts / mini-bursts consistently, with singular forms where appropriate. All numbers and phase identifiers are preserved.
- Add 21 reviewed overrides, including complete plans for surfaces that show an unsplit note. Kalos notes use **curse stacks** instead of the old dictionary's **Magic Stigmas**; compare the [Kalos mechanic description](https://maplestorywiki.net/w/Kalos/Monster).
- Preserve a single inline child when it already contains the complete phrase. Replacing its parent with text detached the React span and could leave Type A's Phase 1 visible after switching to Type B. Repeated switching now updates every row correctly.
- Mark only boss-plan popovers for a height limit based on Radix's available space. A long Kalos plan previously extended below a 320 × 568 screen; it now scrolls within the popup. No character values, game formulas or extension permissions changed.
