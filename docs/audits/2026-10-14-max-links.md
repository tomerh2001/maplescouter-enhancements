# Maximum-level Link Skill comparison, 2026-10-14

Version: 1.7.9.

## Behavior

Added **Max level** to Result > Links/Potentials > Link Skill Eff. It ranks the full bonus at each link's GMS cap. **Lv 2→3** retains its upgrade-only meaning. Selecting either checkbox clears the other; both unchecked retains the existing comparison. The choice is local to the current page session.

The independent max-level catalog includes all 26 damage candidates rather than rescaling only the native top 15. Individual skills use Lv. 3, Explorer groups Lv. 9, Cygnus Lv. 15 and Zero Lv. 6. Shared skills use transferable effects, without owner-only damage bonuses. Character inputs, results, presets and cloud saves are unchanged. There are no added network requests.

The table retains the native timed-effect weighting for Terms and Conditions, Thief's Cunning and Time to Prepare, and the solo assumption for Noble Fire. It still uses local efficiency estimates; buff duration, survival, EXP and uncapped critical-rate valuation outside Vicious Shot are not modeled. Guiding Stars remains an unranked note. See [calculation details](../GMS-LINK-SKILLS.md).
